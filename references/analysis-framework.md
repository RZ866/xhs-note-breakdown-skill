# 按证据拆解商业内容

## 输入分流与可信度

先识别来源，再判断商业任务。材料可有多种角色：title、cover、body、gallery、product、comments、metrics。多张图不自动意味着一篇完整笔记；跨笔记无法归属时按组说明，本版不做多账号统计。

用户明确说明优先用于理解产品、研究意图和更正；它不使模糊截图数字变清楚。例：用户说价格29元，截图写19.9元，分别保存“用户补充29元”和“截图标注19.9元”，说明时间或版本不明，不能静默合并成一个事实。

事实记录包含材料编号和可定位位置：图2底部商品卡、文字段落3、封面左上角。文字摘录尽量短，只保留支持结论的片段。视觉观察分清“画了什么”与“因此可能产生什么作用”。对模糊区域写“看不清”，不要用模型常识补全。

## 分析深度

| 范围 | 必要分析 | 不应补写 |
|---|---|---|
| 只有标题 | 原标题、关键词、搜索意图假设、钩子、点击解释、标题公式、3个学习点（有证据时） | 封面布局、正文过程、实际成交 |
| 只有封面 | 视觉主体、文字、布局、焦点、露出、点击钩子、封面公式、封面DNA、3个学习点 | 没看见的正文、评论、使用结果 |
| 有正文 | 标题（若有）、正文功能、产品植入、流量/停留/信任/成交假设、DNA | 视觉与图片顺序 |
| 完整/多图 | 按可见材料选择下列模块，逐图说明商业任务 | 为了14章而生成空洞模块 |
| 商品/数据/评论片段 | 可见商品信息、指标口径、评论样本及可提出的研究问题 | 硬认成封面或完整笔记 |
| 非典型带货 | 表达方式、点击/阅读价值、适用的内容模型 | 编出在卖什么、强制成交漏斗 |

## 商业信息

产品/解决方案、价格口径、目标人群、场景、痛点、卖点、购买理由、内容类型。明确区分原文人群称谓与分析推测的消费者。类型可主辅并存：解决问题、测评、体验、故事、对比、清单、教程、低价、避坑、情绪、反常识等；没有类型线索就不硬归类。

## 标题：从词到任务

保留原标题；区分原文关键词与潜在搜索词（后者不是搜索量结论）。检查价格、痛点、结果、好奇、身份、场景、时间、数字、冲突、反常识、稀缺或社会证明。重点说明词序与信息兑现预期。

不要只写“低价+痛点”。例如一种可能的结构为“经验暗示→低试错价格→具象生活困扰→结果承诺”，并指出经验暗示不是真实资历、结果承诺不是效果证明。不要把示例固定套到所有标题。

## 封面：先观察再解释

原生看图：主体/人物/产品/场景、文字、信息层级、位置与尺度、产品露出、焦点、构图、颜色对比、生活感/设计感、价格/结果/情绪钩子。

写“左上方深色大字与浅底形成对比，可能先被扫到”，而不是无依据“第一视觉焦点必然是标题”。真人不等于真实体验；前后对比只能证明页面呈现了对比，不能证明效果。没有测量工具不写精确面积百分比。

封面公式包含画面关系，例如“具体场景作背景＋问题作主标题＋解决工具局部露出”。同时指出适用商品和不能迁移的独有素材。

## 图片组：每张图分配可解释的任务

按实际提供顺序逐图标注：材料编号、看到了什么、推测承担的任务、承接了前图什么信息、留下什么疑问。可包括吸引点击、解释场景、展示操作、呈现差异、介绍限制、提示价格。商品页截图可能是用户补充，不自动编进原笔记图片序列。

如果顺序仅为上传顺序，在报告说明“按收到顺序展示，不确定原发布顺序”。连续截图重复部分不要重复算卖点或互动。

## 正文与产品植入

按内容功能切分而非机械段落摘要：开头钩子、情境、问题、问题放大、产品首次出现、卖点、操作、体验、证据、结果陈述、价格、CTA。标出每段发挥什么任务、承诺是否在后文兑现。

产品第一次出现的位置与前置铺垫是什么？以“解决问题的工具”还是“直接推销对象”出现？后续是讲功能、展示过程还是反复促销？广告感强/中/弱只能是有依据的分析判断，例如价格出现频率、购买指令、单向效果声称。结论不等同商业合作披露判断。

## 四段商业逻辑

1. **流量**：选题、关键词、视觉或身份线索可能匹配什么需求？分开潜在搜索与推荐适配，不宣称平台真实流量来源。
2. **停留**：哪些信息需要继续读才能拿到？问题、过程、对比、故事或结果预期在哪里兑现？标题短句不足以判断实际阅读时长。
3. **信任**：哪些材料可能降低疑虑：使用细节、限制、可复验步骤、来源清晰的评论？同时给最强反证或缺口，如没有测试条件、没有效果验证、截图时间未知。
4. **成交**：最大购买理由、最大阻力、试错成本、适用条件、决策复杂度、CTA分别是什么？“价格低”可能降低试用门槛，不能证明购买发生。明确区分“商品兴趣机制”和“实际成交证据”。

成交路径图为**内容机制假设**，不是数据漏斗。不填流量、转化率或阶段人数。非带货内容不显示商品兴趣和成交阶段；标题/封面仅显示材料支持的阶段。

## 爆款 DNA 与学习点

从具体词语转成可迁移的结构关系，保留适用边界：例如“明确困扰→可观察过程→效果与限制并列→低风险试用提示”。四类DNA仅在有证据时写，总公式通常4～6个环节，不把优美句式当结论。

3～5个最值得学的点，每项写：做法 / 为什么可能起作用 / 学结构而不照搬什么 / 验证方法。封面默认3点，但证据少可以更少。避免“标题好、真实感强、情绪到位”这类不可执行判断。

单列不要照搬：独创措辞、原作者身份和家庭故事、照片、未核验数据、效果承诺、虚构案例或第一人称。默认不输出新标题包、选题包或仿写稿。

## 自查

最重要的结论是否有材料定位？有没有将用户说的“爆款”认证为实测结果？有没有从互动跳到成交？有没有把截图中的累计销量归因于该笔记？有没有把用户补充当成图片中看到的内容？是否用未知事实补齐漏斗？是否真正解释机制而非复述原文？
